# vault-security-lab

An educational lab exploring vulnerability classes in ERC-4626-style
vaults. Each vault is paired with working attack proofs-of-concept
and their defenses.

**Not for production use.**

## Structure

- `src/` — vault implementations
- `test/unit/` — behaviour tests
- `test/attacks/` — attack PoCs and defenses
